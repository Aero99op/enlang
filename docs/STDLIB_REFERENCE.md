# EnLang v2.0.0 Standard Library Reference
==============================================================================

Please refer to `spec/stdlib.json` and `spec/builtins.json` for formal machine-readable definitions.

## Built-in Functions
- `length of <seq>`: Returns the number of items.
- `create map` / `{}`: Returns an empty dictionary.
- `create list` / `[]`: Returns an empty list.
- `infinity`: Returns mathematical float infinity.
