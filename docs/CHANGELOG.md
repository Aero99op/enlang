# EnLang Release Changelog
==============================================================================

## [2.0.0-alpha] - 2026-07-28
### Added
- Single Source of Truth specification architecture (`spec/` directory with `enlang_spec.json` manifest).
- Formal reference documentation in `docs/`.
- First-class universal AST nodes definition (`enlang_core/parser/ast_nodes.py`).

## [1.4.7] - 2026-07-28
### Added
- Support for natural English indexing (`s at index left`) and slicing (`s from left to len(s)`).
- Verified 64/64 comprehensive tests pass across all 5 domains.
